# Основы программной инженерии - практические работы

## Lab_2. Типы данных Python, работа с числовыми данными (уровень A)

- **A4** - ввести два целых числа (1..1000) и вывести большее, без ветвлений, циклов и функций (через список или тернарный оператор).
- **A5** - проверить, делится ли A на B нацело; вывести YES или NO, без ветвлений.
- **A6** - по числу секунд N с начала суток вывести время в формате h:mm:ss (минуты и секунды двузначные).
- **A7** - по координатам двух клеток шахматной доски вывести YES, если они одного цвета, иначе NO. Если цвет одинаковый, вывести White или Black ((1,1) - белая).

### Запуск

    python3 Lab_2/A4.py

Аналогично для A5.py, A6.py, A7.py. Числа вводятся с клавиатуры, каждое с новой строки.
